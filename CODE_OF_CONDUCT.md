# Code of Conduct

This project is a small, publicly visible engineering repository. The standard
is simple: treat people with respect, keep discussion technical, and argue
about the work rather than about each other.

## Expected Behaviour

- Communicate respectfully and professionally.
- Keep technical discussion constructive and specific. Criticise the design,
  the code, or the reasoning, and explain why.
- Assume good faith, and ask for clarification before assuming bad intent.
- Accept that disagreement is normal, and that the maintainer will sometimes
  decide against a suggestion for reasons of scope or direction.
- Respect the repository's data rules: synthetic or approved non-sensitive data
  only.

## Unacceptable Behaviour

- Harassment of any kind, including sustained unwanted contact.
- Discrimination or demeaning remarks based on personal characteristics.
- Personal attacks, insults, or hostile language directed at an individual.
- Spam, advertising, or off-topic promotional content.
- Deliberately disruptive behaviour, including derailing discussions, repeated
  bad-faith argument, or trolling.
- Publishing another person's private information without their permission.

## Scope

This Code of Conduct applies to all project spaces — issues, pull requests,
code review comments, discussions, and commit messages — and to any conduct
that directly affects those spaces.

## Enforcement

The maintainer may take any action considered appropriate and proportionate,
including editing or removing comments, closing issues or pull requests,
rejecting contributions, and blocking accounts from further participation.

Enforcement decisions are made by the maintainer and are not a debate forum.
Repeated or severe violations may result in a permanent block without prior
warning.

## Reporting

Report concerns privately rather than in a public thread.

Use the private reporting route described in [`SECURITY.md`](SECURITY.md): a
private GitHub security advisory where that capability is available for this
repository, or the private maintainer contact channel listed on the repository
owner's GitHub profile.

Reports are handled privately and with discretion. Because this is a
maintainer-run portfolio project, no response time is guaranteed.
